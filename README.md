# Frontend To-Do List (Starter)

This is a beginner-friendly starter project for learning:
- HTML (structure)
- CSS (styling)
- JavaScript (interactivity)

By the end of the lesson, you will have a working To-Do List app.

---

## 🚀 Getting Started

1. Open this folder in VS Code
2. Open `index.html` in your browser
3. Start coding!

No installs. No build tools. Just vibes.

---

## 🧠 Learning Goals

- Understand how HTML, CSS, and JavaScript work together
- Use the DOM to create interactive web apps
- Build confidence writing frontend code

---

## ✨ Challenge Ideas

- Add an Enter key shortcut
- Add a delete button per task
- Save tasks using localStorage
- Mark tasks as completed

Have fun and break things (that’s how you learn).
